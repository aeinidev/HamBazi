# Kahroba engine

Pure, disabled, offline K1 module. Public exports are documented in `src/index.ts`; implementation files are private. See `docs/architecture/kahroba-module.md`, `docs/architecture/kahroba-rules.md` and `dataset-provenance.json` from the repository root.

```sh
rtk proxy pnpm --filter @hambazi/kahroba-engine typecheck
rtk proxy pnpm --filter @hambazi/kahroba-engine test
rtk proxy pnpm --filter @hambazi/kahroba-engine build
```

Provide Clock/RandomSource and an explicit versioned rules object. Null timing fields select an untimed offline instance; they are not a production default. Positive timing requires a policy version, and trusted timeout execution additionally requires the caller's matching policy. Imports select no duration, action fallback, server, queue or availability.

Results preserve shared winners in a Kahroba-owned extension. Do not send this result directly to the current platform v1 persistence/parser; K2 mapping/versioning is required. Authentication, Match action IDs/versions, atomic durable writes, admission and recovery are outside this module.

Numeric data and raw resource fixtures are adapted under the retained MIT notice in `LICENSES/splendor-api-MIT.txt`. Original module logic remains under the repository's existing UNLICENSED policy. Inspection-only photographs/scans and upstream engine code are not distributed. Expected data and replay fixtures are checked in and never regenerated by tests.
