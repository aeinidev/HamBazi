No broad grants, hidden-state/event-payload/invite-code/credential reads or writes, destructive migrations, history deletion or public backend ports.
5. Admit only through existing private controller/health and ingress controls; verify existing allowlists and `nginx -t`. Perform only separately authorized live QA. The Phase 3 authenticated limited-role 403 and `ADMIN_REVOKE_SESSIONS` receipt/Audit and revoked-session QA remain open; local tests cannot close them.

Any data restore requires separate assessment of writes since backup, maintenance and explicit authorization. Reopen only with fresh valid security and health evidence.
